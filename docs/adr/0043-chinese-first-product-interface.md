# Chinese-first product interface

Minimalist Agent's product interface will default to Simplified Chinese because the intended usage area is mainland China, while code identifiers, APIs, ADRs, and canonical domain terms may remain English. User-facing copy should translate domain concepts into clear Chinese terms such as 本地账号, 管理员审批, 智能体对话, 运行状态, and 制品预览 instead of exposing internal English labels by default.
