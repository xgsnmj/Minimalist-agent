# shadcn/ui as the owned component layer

Minimalist Agent will adopt shadcn/ui as the owned component layer for `apps/web`. The frontend will keep its OpenAI-inspired product design system and production workbench interface principles, but implement reusable controls, overlays, and data-display primitives as local source code generated by shadcn/ui. The implementation will sit on Tailwind CSS and Radix-based primitives, while custom composition remains the default for domain-specific Agent Conversation and Administrator Console surfaces.

This decision refines ADR-0006 and ADR-0042 without changing their product intent.

## Decision

1. Use shadcn/ui for reusable frontend primitives in `apps/web`.
2. Keep the product design system and page composition custom; do not turn shadcn/ui into a wholesale app theme.
3. Prefer shadcn/ui for generic controls, forms, dialogs, tabs, badges, cards, separators, tooltips, and similar repeated patterns.
4. Keep bespoke workbench layouts, conversation flows, and admin screens as feature-owned compositions on top of the shared primitives.

## Consequences

- Common UI work gets cheaper and more consistent.
- The frontend gains an inspectable, repo-owned primitive layer.
- The initial setup requires Tailwind/shadcn configuration and a one-time migration pass.
- Highly domain-specific screens still need custom composition rather than forcing everything into a component catalog.
